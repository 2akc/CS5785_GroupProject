# data/ (gitignored)

Download from the Kaggle **Data** tab and put these files here:
`train.csv`, `unlabeled.csv`, `test.csv`, `train_starter_2000.csv`, `sample_submission.csv`.

`split_ids.json` is created automatically on the first run, and it's the same for everyone.
Data somewhere else (e.g. Kaggle)? Set `AIHUMAN_DATA_DIR=/path`.
